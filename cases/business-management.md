# Business Management Application

## Problem

A small organization needed a centralized internal system for operational records, user access control and management dashboards instead of relying on fragmented manual workflows.

## Solution

I developed a web application with authentication, role-based access, relational storage, dashboards and spreadsheet processing.

## Stack

- Python
- NiceGUI
- FastAPI
- SQLModel
- PostgreSQL
- Alembic
- Pandas
- OpenPyXL
- JWT
- Docker

## Main capabilities

- role-based administration;

- dashboards;
- Excel data processing;
- database migrations;
